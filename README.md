# Next Academy · Práctica de Docker

Una práctica guiada para aprender los fundamentos de Docker a partir de una aplicación web sencilla: un contador de visitas creado con Python y Flask.

Durante el recorrido construirás imágenes, trabajarás con contenedores y puertos, persistirás datos con volúmenes y coordinarás servicios con Docker Compose y Redis.

## Objetivos de aprendizaje

- Crear y ejecutar una imagen Docker.
- Publicar una aplicación web desde un contenedor.
- Conservar datos mediante volúmenes.
- Versionar imágenes con etiquetas.
- Ejecutar una aplicación multicontenedor con Docker Compose.

## Empieza aquí

Todo el material para el alumnado está en [`practica/`](practica/). Sigue las instrucciones de su [guía paso a paso](practica/README.md).

## Requisitos

- Python 3
- Docker Engine
- Docker Compose

La guía incluye los pasos de instalación y verificación para Ubuntu.
